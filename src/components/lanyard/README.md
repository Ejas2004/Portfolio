# Lanyard Component Assets

## Required Files

You need to add the following files to this directory:

1. **card.glb** - 3D model file for the ID card
2. **lanyard.png** - Texture image for the lanyard band

## Where to Get These Files

Download these files from the ReactBits example repository:
- Repository: https://reactbits.dev/r/Lanyard-JS-CSS
- Or from: https://github.com/nakleiderer/reactbits (check the lanyard example)

Place both files in: `src/components/lanyard/`

## Customization

### Editing the Card (card.glb)
You can customize the card texture using this online .glb editor:
- https://modelviewer.dev/editor/

### Editing the Lanyard Band (lanyard.png)
Edit the lanyard.png file in any image editor (Photoshop, GIMP, etc.) to customize the band design.

## Important Notes

- The Vite configuration has been updated to support .glb files
- Make sure both files are in place before running the development server
- The component will fail to load without these assets
